# audio

배경 음악 자리입니다. 이 이름으로 넣으면 낮 · 밤에 따라 자연스럽게 바뀝니다.

- `bgm-day.mp3` → 낮 음악
- `bgm-night.mp3` → 밤 음악

파일이 없으면 음악 없이 조용히 넘어갑니다 (장작 · 빗소리 · 책장 · 시냇물 · 새 · 풀벌레 소리는 브라우저가 직접 만들어서 파일이 필요 없어요).
반복 재생되므로 앞뒤가 이어지는 곡이 좋고, 폰 데이터를 생각해 곡당 3~5MB 이하를 권합니다.
다른 이름이나 형식(.m4a, .ogg)을 쓰려면 `js/config.js` 의 `music` 을 고치세요.
