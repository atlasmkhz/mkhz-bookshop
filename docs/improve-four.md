# 서점 다듬기 네 가지 — Claude Code 작업 지시서 (2026-11-04)

이 글은 서점지기(박효순)가 Claude Code 에게 맡기는 작업 지시서입니다. 저장소 atlasmkhz/mkhz-bookshop 에서만 작업합니다.
먼저 CLAUDE.md 를 끝까지 읽고 그 규칙을 그대로 지켜 주세요. 답과 안내는 한국어로, 쉬운 말로, 굵은 글씨(**)와 ## 소제목 없이 해 주세요.

## 이번 작업의 원칙

- 기능을 새로 늘리는 작업이 아닙니다. 이미 있는 것을 처음 온 손님이 알아보고, 다시 오고 싶게 다듬는 작업입니다.
- 네 가지 모두 서버 메시지를 새로 만들지 않습니다(메시지 0건). Cloudflare 무료 한도 계산이 바뀌지 않아야 합니다.
- 남이 쓴 글을 서점에 거는 기능(방명록 등)과 서점지기가 매일 글을 써야 하는 기능(오늘 한 줄 등)은 만들지 않습니다. 관리 부담 때문에 뺀 것입니다.
- 미술관(gallery)은 닫힌 그대로 둡니다. 건드리지 않습니다.
- 서버 이름(mkhz-bookshop · mkhz-gallery), 저장소 이름, 주소(bookshop.mkhz.kr)는 바꾸지 않습니다. 서버 이름을 바꾸면 손님 화면이 서버를 못 찾습니다.
- 순서대로 하나씩 끝내고, 하나 끝날 때마다 PC 화면과 휴대폰 화면(390 × 844) 스크린숏으로 확인합니다.

## 1. 이름과 들어가기 화면 소개

이름은 아직 정하지 않았습니다. 지금 이름(엠케이아틀라스 서점)을 그대로 두고, 나중에 한 줄만 고쳐 바꿀 수 있게 준비만 합니다.
- 이름: 엠케이아틀라스 서점 (후보: 고양이서가 숲속 책방 등, 서점지기가 정하면 바꿈)
- 소개 한 줄(정함): 책을 읽는 사람들의 작은 숲
- 덧붙이는 말: 책은 엠케이아틀라스의 역사 · 철학 · 과학 · 정치 아틀라스에서 왔어요

할 일
1. js/config.js 에 이름을 한곳에 모읍니다. 예: brand: { name: '엠케이아틀라스 서점', short: 'MK 서점', tagline: '책을 읽는 사람들의 작은 숲', credit: '책은 엠케이아틀라스의 …에서 왔어요' }. 화면 글자는 모두 여기서 가져오게 합니다. 이름은 앞으로 또 바뀔 수 있으니, 한 줄만 고치면 화면 전체가 바뀌어야 합니다.
2. 자바스크립트를 읽지 않는 곳(링크 미리 보기, 검색 로봇)을 위해 index.html 의 description 에 소개 한 줄을 넣습니다. title · og:title · og:site_name 은 이름이 정해질 때 같이 바꿉니다. 이 칸들은 config 를 못 읽으니, config 의 brand 를 바꾸면 index.html 도 같이 바꿔야 한다고 CLAUDE.md 에 한 줄 적어 둡니다.
3. 들어가기 화면(index.html 의 .logo 두 곳 · .sub)과 불러오기 화면(#loading), 왼쪽 위 꼬리표(short)가 config 에서 이름을 가져오게 바꾸고, 들어가기 화면 이름 아래에 소개 한 줄을 넣습니다.
4. 들어가기 화면 소개글은 「무엇을 할 수 있는지」가 보이게 다시 씁니다. 길게 쓰지 말고 두 줄 안쪽으로. 예: 책을 꺼내 읽고, 책상에서 한 문장을 옮겨 적고, 모닥불 가에 앉아 쉬어 가는 곳이에요. 혼자 와도 괜찮아요.
5. README 첫머리에 소개 한 줄을 넣고, 「이름을 바꿀 때 고칠 곳」(config brand · index.html 의 title 과 og 칸 · README · admin.html 제목)을 적어 둡니다.
6. 배포 뒤 카카오톡 링크 미리 보기용으로 og.jpg 주소 뒤의 판 번호(?v=2)를 하나 올립니다.

## 2. 첫 방문 길잡이와 꾸미기 접기

꾸미기 접기
1. 들어가기 화면에서 이름 칸과 「들어가기」 단추만 먼저 보이게 하고, 옷 · 머리 · 피부 · 머리형 · 아래옷 · 소품은 「🎨 꾸미기」 단추를 눌러야 펼쳐지게 접습니다.
2. 처음 온 손님은 겉모습을 알아서 골라 둡니다(LOOKS 안에서 고르게 섞되 성별을 가정하지 않기 — CLAUDE.md 손님 외형 규칙). 미리 보기 그림판은 접힌 상태에서도 작게 보여 「아, 이게 나구나」를 알게 합니다.
3. 전에 고른 모습이 있으면 그대로 쓰고, 꾸미기를 펼치지 않아도 됩니다.

첫 방문 길잡이
1. 이 기기에서 처음 들어온 손님에게만, 들어간 직후 화면 위에 작은 길잡이 카드를 띄웁니다(store 'guide'). 한 번 끝내거나 「그만 보기」를 누르면 다시 안 나옵니다. 화면 오른쪽 위 어딘가에 「길잡이 다시 보기」를 작게 둡니다.
2. 세 걸음입니다. 각 걸음은 이미 있는 「가볼 곳」 걸어가기를 그대로 씁니다.
   - 책 한 권 꺼내 보기: 가까운 책장으로 안내 → 책을 누르면 다음 걸음
   - 책상에 앉아 한 문장 옮겨 적기: 필사 책상 자리로 안내 → 필사를 시작하면(끝까지 쓰지 않아도) 다음 걸음
   - 모닥불 가에 앉아 쉬기: 가장 가까운 모닥불로 안내 → 앉으면 끝, 「이제 마음대로 돌아다녀 보세요」
3. 카드는 그림 화면 위에 띄웁니다(서점지기 규칙: 설명은 판 아래가 아니라 그림 위에). 글은 한 줄씩 짧게, 「건너뛰기」 「그만 보기」 단추를 둡니다.
4. 휴대폰에서 아래 단추 여섯 개와 겹치지 않는지 확인합니다.
5. 메시지 0건. 다른 손님 화면에는 아무것도 보이지 않습니다.

## 3. 필사 공책: 연속 일수 · 달력 · 글로 복사하기

지금 모습: js/copydesk.js finish() 가 store 'copybook' 에 { id, no, ko, src, theme, url, day, acc, min } 를 쌓고(200편까지), js/ui.js openCopybook() 이 목록을 보여 줍니다.

1. day 를 한국 날짜로 바꿉니다. 지금은 toISOString 이라 한국 시각 새벽 0~9시에 쓴 편이 전날로 찍힙니다. 이미 쌓인 기록은 그대로 두고, 새 기록부터 한국 날짜(kstDay 와 같은 기준)로 남깁니다.
2. 공책 맨 위에 세 가지를 둡니다.
   - 연속 일수: 오늘(또는 어제)까지 하루도 빠지지 않고 쓴 날 수. 「🔥 3일째 이어 쓰는 중」처럼.
   - 이번 달 달력: 쓴 날에 도장(작은 잉크 자국)을 찍은 한 달 칸. 지난달 · 다음 달로 넘겨 볼 수 있게.
   - 지금까지 쓴 편 수와 글자 수.
3. 「📋 글로 복사하기」 단추: 공책 전체를 날짜 · 문장 · 출처 순의 글로 복사합니다. 휴대폰 메모나 카톡에 붙여 넣어 보관할 수 있게. 복사가 안 되는 브라우저에서는 글을 띄워 직접 고르게 합니다.
4. 「이 기기에만 저장돼요. 기기를 바꾸거나 방문 기록을 지우면 사라지니, 가끔 글로 복사해 두세요」를 공책 위쪽에 잘 보이게 둡니다.
5. 200편 제한은 그대로 둬도 되지만, 넘칠 때 오래된 편부터 사라진다는 것을 같은 안내에 적습니다.
6. 메시지 0건. 서버에 올리지 않습니다.

## 4. 개인정보 안내 쪽

1. privacy.html 한 쪽을 만듭니다(서점 화면과 같은 글꼴 · 색, 휴대폰에서 읽기 쉽게). 들어가기 화면 맨 아래와 건의함 창 아래에 「개인정보 안내」 링크를 작게 둡니다.
2. 글은 실제 코드를 읽고 사실대로만 씁니다. 지어내지 않습니다. 아래는 제가 확인한 것이고, 작업 때 다시 확인해 주세요.
   - 가입이 없고 이름(닉네임)만 받습니다. 이름과 겉모습은 같은 방 손님에게 보입니다.
   - 채팅은 서버에 저장하지 않습니다(server/src/index.js 가 전하기만 함). 기록은 각자 화면에만 있다가 나가면 사라집니다.
   - 건의함에 쓴 글과 이름, 방 번호는 서점지기가 읽을 수 있게 저장됩니다. 도배를 막으려고 접속 주소(IP)를 그날 하루 동안만 셉니다(limit). 실제 보관 기간과 지우는 방식은 코드에서 확인해 그대로 적습니다.
   - 서버가 붐비거나 막히면 손님끼리 직접 이어지는데, 이때 서로의 인터넷 주소(IP)가 연결에 쓰인다는 것을 한 줄로만 부드럽게 적습니다. 예: 「손님이 많을 때는 손님끼리 바로 이어지기도 해요. 이때 연결을 위해 인터넷 주소가 쓰이지만, 이름이나 사는 곳이 드러나지는 않아요.」 겁주는 말투로 쓰지 않습니다. 서점지기가 빼자고 하면 뺍니다.
   - 이 기기에만 남는 것: 필사 공책 · 나무 다듬기 작품 · 겉모습 · 소리와 화면 설정 · 길잡이 본 기록 · 우리 집 고양이(사진은 기기 안에서만 쓰고 올리지 않음 — ui.js 문구 확인).
   - 사이트는 GitHub Pages, 서버는 Cloudflare 에서 돌아가며, 두 회사도 접속 기록을 남길 수 있습니다.
   - 어린이 손님도 올 수 있으니, 이름에 진짜 이름 · 학교 · 전화번호를 쓰지 말라고 부탁합니다.
3. 문의처는 서점지기의 공식 메일로 적되, 어떤 주소를 쓸지 배포 전에 서점지기에게 꼭 확인받습니다.
4. 딱딱한 법률 문서처럼 쓰지 말고, 짧은 문단 여러 개로 쉽게 씁니다.
