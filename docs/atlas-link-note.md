# 네 아틀라스에 「고양이책과방」 링크 붙이기 — 아틀라스 작업 세션용 짧은 지시문

이 글은 역사 · 철학 · 과학 · 정치 아틀라스 각각의 작업 때 그대로 붙여 넣는 지시문입니다. 네 곳에 똑같이 적용합니다.
각 아틀라스의 평소 작업 규칙(CLAUDE.md, SEO 파이프라인, 전체 ZIP 하나로 전달 등)을 그대로 따릅니다.

새로 생긴 형제 공간
- 이름: 고양이책과방
- 소개: 책을 읽는 사람들의 작은 숲 · 고양이가 사는 숲속 책방
- 주소: https://bookshop.mkhz.kr/
- 성격: 네 아틀라스의 글이 한 권씩 책이 되어 꽂힌 3D 숲속 독립서점. 가입 없이 들어가 책을 꺼내 읽고, 문장을 옮겨 적고, 모닥불 가에서 쉬어 가는 곳

할 일
1. 바닥글의 형제 사이트 줄(모든 쪽에 들어가는 sibling footer)에 「고양이책과방」 한 칸을 더합니다. 다른 형제와 같은 모양으로, 링크는 https://bookshop.mkhz.kr/ 로.
2. 대문(첫 화면)에 작은 카드나 링크 하나를 둡니다. 예: 「이 아틀라스의 글을 책으로 꺼내 읽기 · 고양이책과방에서 →」. 대문을 어지럽히지 않게, 이미 있는 「다른 아틀라스」 묶음 근처에.
3. 구조화 데이터(Organization JSON-LD)에 형제 사이트 목록이 있으면 같은 곳에 서점 주소를 더합니다.
4. 링크는 새 탭으로 열리게 하지 않아도 됩니다(형제 사이트와 같은 방식).
5. SEO 파이프라인을 평소대로 돌리고(바닥글이 바뀌면 쪽 전체가 바뀌므로), 점검을 거친 뒤 전체 ZIP 하나로 전달합니다.
