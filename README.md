# 엠케이아틀라스 서점 (mkhz-bookshop)

역사 · 철학 · 과학 · 정치 아틀라스의 자료실 시리즈가 한 권씩 책이 된 **온라인 독립서점**입니다.
숲속 통나무 오두막 서점과 루프탑, 문을 나서면 캠핑장 · 숲속 영화관 · 폭포가 있는 계곡 · 남쪽 바닷가까지 이어지는 넓은 숲.
핵심은 "숨는 곳"과 "돌아다니는 맛" — 탁 트인 광장이 아니라, 가려진 구석이 곳곳에 있고 길이 갈래로 갈라집니다.
고양이서가 카페(캣타워 · 고양이 · 내 고양이)를 이 안으로 합쳤습니다.

주소: https://atlasmkhz.github.io/mkhz-bookshop/ · 서점지기 건의함: https://atlasmkhz.github.io/mkhz-bookshop/admin.html

- 고양이서가 카페 엔진을 가져와 다시 지음: Three.js 3D, Cloudflare 방 서버(방 하나 100명), 서버가 막히면 P2P 자동 전환, 낮 · 밤, 앉기, 고양이, 톡 · 끌기 · 꾹 누르기 · 키보드 조작
- 책 84권 · 960편 (역사 57 · 철학 7 · 과학 12 · 정치 8). 앉을 자리 211곳, 그중 숨은 자리 79곳
- 설치 · 가입 없음, 폰 · PC

## 숲속 영화관 (유튜브 채널 자동 상영)

- 상영 목록은 `data/program.json`. `items` 가 비어 있으면 엠케이아틀라스 채널에 올린 영상 전체(`playlist`)를 15분마다 다음 것으로 틉니다.
- 대표 영상 모음을 만들면 `items` 에 적으세요: `{"id": "유튜브 v= 값", "title": "제목", "min": 길이(분)}` 여러 개. 그러면 모든 손님이 지금 시각으로 "몇 번째 영상의 몇 분 지점"을 각자 계산해 같은 장면을 봅니다 (서버를 쓰지 않습니다).
- 3D 스크린에는 글자 포스터(지금 상영 중인 제목 · 진행 띠)가 보입니다. 영상 썸네일이 불러와지면 그것이 보이고, `video/screen-loop.mp4` 를 넣으면 짧은 예고 영상이 소리 없이 흐릅니다.
- 영화관 자리에 앉으면 화면 위에 유튜브 플레이어가 열립니다(크게/작게/닫기). 일어나면 닫힙니다. 스크린이나 매표소를 누르면 상영표.

## 손님이 하는 일

- 책등을 누르면 표지와 목차가 펼쳐짐 → 「담기」로 책바구니에. 🧺 책바구니는 어디서든 열어 편을 골라 읽기(아틀라스 실제 글이 새 창으로). 읽은 편 표시, 「서가 둘러보기」, 「꽂힌 자리로」
- 책바구니 · 읽은 편 · 이름 · 음료 · 내 고양이는 그 브라우저에 저장
- ☕ 카운터(서점 · 바닷가 매점)에서 음료 고르기, 다른 손님을 눌러 음료 선물 · 인사 · 가리기
- 💬 말풍선 채팅: 9m 안의 사람에게만. 거친 말 거르기, 연속 입력 제한, 특정 손님 가리기
- 고양이 책갈피 · 먹물 · 삼색이 · 고등어: 쓰다듬기, 간식 주기. 캣타워 · 사다리 · 바위를 오르내리고 손님 곁에 와서 앉음. 돌발행동 — 우다다, 평대 위 책 떨어뜨리기, 나비 쫓기, 벽 보기, 다른 고양이에게 덮치기, 문 앞에서 야옹, 시냇물 보고 깜짝, 텐트에 들어가기, 밤에 스크린 앞에 앉기
- 🐾 우리 집 고양이: 사진을 올리면 털색을 따서 나를 따라다님 (사진은 기기 안에서만)
- 🌌 별멍 (밤 · 바깥 · 비 안 올 때): 오른쪽 아래 「별멍」 단추 → 가까운 빈자리에 앉아 하늘을 올려다봄. 은하수 · 초승달 · 별자리(북두칠성 · 북극성 · 카시오페이아 · 오리온 · 견우성과 직녀성) 선과 이름, 9초마다 정해지는 별똥별(모든 손님이 같은 순간에 봄). 끌면 하늘 둘러보기
- 🎆 바닷가 폭죽 놀이 (밤): 바닷가 서쪽 모래밭의 폭죽 상자 → 국화 · 버드나무 · 하트 · 별 · 고리 · 연발 다섯 발 · 불꽃막대. 쏘면 카메라가 바다 위 하늘로 고개를 듦. 같은 방의 밤 손님도 같은 모양 · 같은 색으로 봄
- 🐾 캣타워 놀이터: 캣타워를 누르면 이름 · 크기와 함께 「숨은 아깽이 찾기」(아기 고양이 꼭꼭이가 숨숨집 하나에 숨음, 🐾 표시를 눌러 찾기, 10초 뒤 반짝이는 눈 힌트)와 「고양이 불러 놀기」(가까운 고양이가 캣타워를 올라가 장난감을 향해 펄쩍)
- 🧸 고양이 장난감 대여 (카운터 왼쪽 바구니 · 카운터 창의 장난감 탭, 무료): 깃털 낚싯대 · 레이저 포인터 · 방울 공 · 쥐 인형 · 캣닢 쿠션. 들고 고양이를 누르면 장난감마다 다르게 놂(펄쩍 · 우다다 · 공 쫓기 · 덮치기 · 뒹굴). 다른 손님 손에도 보임
- 카운터 오른쪽 끝 「고양이서가」 작은 안내판: 이 서점 캣타워를 만든 고양이서가 스마트스토어로 가는 유일한 자리 (캣타워 카드엔 링크 없음)
- 🔥 불멍 · 장작 넣기: 캠핑장 모닥불 · 루프탑 화로 · 바닷가 모닥불 옆에 장작더미, 실내 벽난로 옆엔 장작 바구니. 장작더미나 불을 누르면 걸어가서 장작을 던져 넣고, 불길이 확 일어나 불티가 날림. 장작 하나는 2분 30초쯤 타고 여러 개 넣으면 더 크게 오래 탐(낮에도 피울 수 있고, 밤엔 장작 없이도 은은하게). 불 곁에 서면 「장작 넣기 · 불멍」 단추가 뜨고, 불멍을 누르면 불 곁 빈 의자에 앉아 카메라가 불 앞으로 다가가며 단추들이 숨음. 가까이 갈수록 타닥타닥 소리가 커짐. 장작더미는 40초마다 한 개씩 다시 채워짐
- 진돗개 강아지 백구 · 황구: 서점 밖 마당 · 캠핑장 · 영화관 옆 · 바닷가 · 들꽃 언덕 · 정자 · 계곡 가 20곳을 둘이 같이 산책 (한 바퀴 약 14분). 킁킁 냄새 맡기, 땅 파기, 놀자 자세, 서로 빙글빙글 쫓기, 낮잠. 누르면 꼬리를 흔들며 왈, 가까이 서면 쳐다봄. 서버 메시지를 쓰지 않고 지금 시각으로 각자 계산하므로 모든 손님에게 같은 자리에 보이고 하루 요청 수는 그대로
- ☀️/🌙 낮밤, ☔ 빗소리, 🔈 소리(장작 · 책장 · 시냇물 · 폭포 · 파도 · 새 · 풀벌레 · 골골송)

## 책 만들기 (data/books.json)

```bash
python3 scripts/build_books.py
```

네 아틀라스 저장소가 이 폴더 옆(../atlas, ../philo-atlas, ../science-atlas, ../politics-atlas)에 있어야 합니다. 다른 곳이면 `--src 폴더`. 네 저장소는 읽기만 합니다. 필요한 것: python3, node, Pillow.

둘째 판부터는 자료실 시리즈만이 아니라 네 아틀라스에 있는 모든 글을 책으로 묶습니다 (223권 · 4,778장 · 도구 110개). 분야는 여섯입니다.

| 분야 | 들어가는 것 |
|---|---|
| 역사 | 역사아틀라스 자료실 시리즈 · 시대별 사건 연표(7권) · 인물 사전 · 이야기 루트(답사) · 역사의 흐름 · 역사 달력 · 물어보기 · 담사 |
| 철학 | 철학아틀라스 시리즈 · 사상가 열전(분야별) · 질문 · 논쟁 · 용어집 · 베껴 쓰기 노트 · 양자 이야기 |
| 문학 | 고전문학 · 근현대문학 루트(역사) · 서사시 · 고전 읽기 · 노벨문학상 · 말모이(철학) |
| 예술 | 미술사 루트(역사) · 예술 길(철학: 명화 · 국악 · 한국미술 · 거장) |
| 과학 | 과학아틀라스 자료실 · 발견 카드(갈래별 7권) · 인물 · 용어집 · 어린이 과학(초등 3~6학년) · 중학 과학 · 수학 · 과학 대사관 · 오늘의 과학(달별) · 한 감독의 질문 |
| 사회 | 정치아틀라스 전부(법 · 권력 · 읽을거리 · 정치의 기초 · 주거 · 미국 정치 · 복지 · 생활 · 정책 기록 · 오늘의 정치) · 역사아틀라스의 형벌 · 권력 · 검찰 기록 |

- 과학은 학년이 더 붙습니다: 초등 3~4학년 · 초등 5~6학년 · 중학교 · 일반. 서가 목록 창의 과학 탭에서 학년으로 거릅니다.
- 책 한 권 = 제목, 부제, 장 수, 첫 문장 한 줄, 한 줄 소개, 각 장의 실제 주소(목차). 주소는 아틀라스 글 파일의 canonical 을 그대로 씁니다.
- 같은 시리즈가 두 곳에 있으면 한 곳에만: 철학 > 과학 > 정치 > 역사
- 도구(지도 · 놀이판 · 계보 · 연표 · 검색)는 책이 아니라 `tools` 에 따로 담고, 오두막의 도구 손수레나 서가 목록 창의 「도구 모음」 탭에서 새 창으로 엽니다.
- 표지: 시리즈 히어로 그림이 있으면 4:3으로 잘라 `assets/covers/` 에 복사(157권), 없으면 제목 글자로 코드가 그림. 책등 색은 분야 색(역사 붉은 갈색, 철학 짙은 남색, 문학 자주, 예술 주황, 과학 청록, 사회 올리브)
- 같은 스크립트가 `data/program.json` 의 items 가 비어 있으면 역사 · 과학 아틀라스에 적힌 채널 영상으로 채웁니다. 대표 영상 모음을 만들면 items 를 통째로 바꾸면 됩니다.

오두막 안에서 보는 법: 책장 통로마다 그 분야의 「도서목록」 판이 서 있고(역사 · 문학 · 사회 · 철학 ·예술, 학년별 과학은 둥근 탁자 옆 낮은 책장, 과학 일반은 높은 책장), 판을 누르면 그 분야의 서가 목록 창이 바로 열립니다. 도구 손수레는 건의함 옆입니다. 아래 책바구니 버튼에서도 서가 목록 · 도구 모음 탭으로 갈 수 있습니다.

## 방 서버 (Cloudflare) 처음 한 번 설정 — 고양이서가 카페와 같은 방식

1. Cloudflare 대시보드 → My Profile → API Tokens → Create Token → Edit Cloudflare Workers 템플릿으로 토큰 만들기
2. Cloudflare 대시보드 Workers 화면에서 Account ID 복사
3. GitHub 레포 → Settings → Secrets and variables → Actions → New repository secret
   - `CLOUDFLARE_API_TOKEN` = 1번 토큰
   - `CLOUDFLARE_ACCOUNT_ID` = 2번 ID
   - `ADMIN_KEY` = 건의함 목록을 여는 열쇠 (아무 긴 글자, 선택)
4. GitHub 레포 → Actions → Deploy bookshop server → Run workflow

서버 주소가 `js/config.js` 의 `serverUrl` 에 자동으로 적힙니다. 서버가 없는 동안에는 P2P로 동작하고, 건의함 글은 손님 브라우저에 모아 두었다가 서버가 생기면 보냅니다.

- 방 인원 `ROOM_CAP`(100) · 방 개수 `MAX_ROOMS`(5) · 말풍선 거리 `CHAT_RANGE`(12m): `server/wrangler.toml`
- 건의함: 서버에 저장(최근 2,000건). 한 사람 하루 5번, 서점 전체 하루 300건까지

## 무료 플랜(Workers Free)으로 버티는 방법

무료 한도는 하루 요청 10만 건 · 실행시간 13,000 GB-s이고, 넘으면 오류가 납니다. 그래서:

- 서버는 WebSocket Hibernation API를 써서 메시지가 없을 땐 잠듭니다. 서버 쪽 타이머 · 알람 없음
- 연결 유지용 ping(50초마다)은 서버를 깨우지 않는 자동 응답
- 손님 위치는 움직일 때만: 톡으로 걸으면 목적지 1번 + 도착 1번, 키보드로 움직일 땐 1초에 3번 이하
- 고양이는 좌표 대신 "어디로 간다 · 무엇을 한다"는 계획만 (걸을 길도 계획에 같이). 혼자 있는 방에선 보내지 않음
- 채팅은 서버가 가까운 손님에게만 전달, 보내는 쪽도 가까이 아무도 없으면 보내지 않음. 음료 선물은 받는 사람 한 명에게만
- 영화관의 함께 보기는 시계로만 맞춤 (메시지 0건)
- 고양이와 놀기는 누를 때만 'play' 한 건(1.5초에 한 번) — 간식 주기와 같은 길로 고양이 담당 브라우저가 계획을 세움. 폭죽은 쏠 때만 'fw' 한 건(3초에 한 번, 종류 · 씨앗값만 보내 모두 같은 모양으로 터짐). 별멍 · 별똥별 · 숨은 아깽이 찾기 · 장난감 흔들기 모습은 메시지 0건(빌린 장난감은 이미 있는 'hi' 에 한 칸 더). 한 사람이 한 시간 동안 고양이와 40번 놀고 폭죽 30발을 쏴도 들어오는 메시지 70건 — 서버 요청으로 치면 몇 건 수준입니다
- 장작 넣기는 누를 때만 'log' 한 건. 한 사람 2.5초에 한 번까지, 불 20 m 안에 다른 손님이 있을 때만 보내고 서버도 20 m 안의 손님에게만 전합니다. 불 세기를 맞추는 주기 메시지는 없습니다(늦게 온 손님은 그 뒤에 넣은 장작부터 함께 봄). 불멍하며 한 시간에 장작 30개를 넣어도 들어오는 메시지 30건 — 하루 요청 수에는 거의 보이지 않습니다
- 서버가 막히면 손님 화면은 자동으로 P2P로 넘어가 계속 머뭅니다. P2P 한 무리는 20명

손님 1명이 1시간 머물면 요청 약 8~9건 → 하루 약 1만 손님-시간. 손님이 늘 있는 방은 계속 깨어 있어 방 하나가 하루 종일 깨어 있으면 실행시간 한도의 약 83%를 쓰므로 `MAX_ROOMS` 는 5입니다. 실제 사용량은 Cloudflare 대시보드 → Workers → Durable Objects 에서 확인하세요.
